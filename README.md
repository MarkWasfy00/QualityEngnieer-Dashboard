# تحليلات جودة العربيات 🚗

برنامج لمهندس الجودة في معرض العربيات: بتسجّل فيه **الفحوصات، العيوب، أوامر الصيانة، وشكاوى العملاء**، وبيطلعلك لوحة متابعة بالمؤشرات والرسومات، وبيصدّر **تقارير إكسيل و PDF** منسقة بالعربي.

## التشغيل لأول مرة

**على ويندوز:** دبل كليك على `run-app.bat` — بيجهز ملف `.env` الأول، وبعدين بيثبت ويجهز قاعدة البيانات ويبني البرنامج (أول مرة بس) ويفتحه في المتصفح على http://localhost:3000.
لو عايز تجبره يبني من جديد: `run-app.bat rebuild`.

**يدوي:**

```bash
npm run setup     # تثبيت الحزم + إنشاء ملف .env + إنشاء قاعدة بيانات فاضية
npm run dev       # افتح http://localhost:3000
```

لو عايز بيانات تجريبية للتجربة: `npm run db:seed` (⚠️ بيمسح أي بيانات موجودة).

للتشغيل النهائي (أسرع):

```bash
npm run build && npm start
```

## الأوامر المفيدة

| الأمر | الوظيفة |
|---|---|
| `npm run db:seed` | يمسح البيانات ويحط بيانات تجريبية من جديد (⚠️ بيمسح بياناتك) |
| `npx prisma studio` | يفتح قاعدة البيانات في المتصفح للتعديل المباشر |

## الصفحات

- **لوحة المتابعة**: نسبة النجاح من أول مرة، العيوب المفتوحة، تكلفة الإصلاح، نسبة رجوع العربيات، مدة التسليم، رضا العملاء، مع فلتر بالتاريخ.
- **العربيات / الفحوصات / العيوب / أوامر الصيانة / الشكاوى**: إضافة وتعديل ومسح، مع بحث وفلاتر وترتيب.
- **الفحص**: قائمة بنود جاهزة (موتور، فرامل، صاج، كهرباء…)، والنتيجة بتتحسب لوحدها. وتقدر تنزّل **شهادة فحص PDF** لكل عربية.
- **التقارير والتصدير**: تختار الفترة والأقسام وتنزّل:
  - **إكسيل**: شيت ملخص وشيت لكل قسم، الشيتات من اليمين للشمال، بألوان للخطورة والحالة، وفلاتر، وإجماليات بمعادلات، وجاهزة للطباعة.
  - **PDF**: صفحة مؤشرات ورسومات، وبعدها جداول لكل قسم.

## رفع ملفات الإكسيل والتقارير

من **رفع ملفات إكسيل** في القايمة: اسحب ملف أو كذا ملف مرة واحدة، والبرنامج بيعرف نوع كل شيت لوحده وبيطلع لكل نوع صفحة تقرير (مؤشرات، رسومات، تقسيمات، قوايم مهمة) و**PDF** و**إكسيل**. كل التقارير في صفحة **تقارير الإكسيل** (`/data`).

| نوع الشيت | التقرير |
|---|---|
| المديونيات (البنوك) · قيود المبيعات من أودو | أداء التحصيل · تحليل المبيعات |
| مبيعات التقسيط (فواتير) · مبيعات البنوك (تمويل وعمولات وكاش باك) · مبيعات المستعمل | الإيراد، الربح والهامش، حسب الفرع/الماركة/البياع/البنك، اللي لسه متحصّلش |
| مديونية عملاء الفرع · أرصدة العملاء (من غير عناوين) | الباقي على العملاء، حسب النوع والبياع، وعمر المديونية |
| مطالبات الشركات (شيت لكل شركة) | المطلوب، اللي اتستلم واللي لسه، الشيكات، والرصيد عند كل شركة |
| المخزون حسب الماركة · أرقام الشاسيه في أودو · الكميات · الجرد · رصيد الأصناف | المخزون حسب الماركة والمخزن، المتاح وقيمته وعمره، فروق الجرد |
| أذون الاستلام والتسليم · حركة المخازن · تقييم المخزون | الاستلام والتسليم لكل معرض ومخزن بالأسبوع/الشهر، وقيمة الداخل والخارج |
| جهات الاتصال · أي جدول تاني | ملخص حسب الشركة والمندوب · ملخص تلقائي من عناوين الأعمدة |

- شيتات «الوضع الحالي» (المخزون، الجرد، المديونيات، مطالبات الشركات) كل ملف جديد بيستبدل نسختها القديمة.
- شيتات الحركة (المبيعات، الأذون، الحركات) بتتحدّث وتتضاف من غير تكرار — رفع نفس الملف مرتين مش بيكرر حاجة.
- الخلايا اللي فيها معادلات من غير قيمة محفوظة (زي الربح والمتبقي) بتتحسب تلقائي، والتواريخ اللي في المستقبل بتتساب مع تنبيه.

## الإعدادات

- اسم الإدارة أو المعرض اللي بيظهر في التقارير: حط في ملف `.env`:
  `NEXT_PUBLIC_DEALERSHIP_NAME="اسم المعرض"`
- البيانات محفوظة في ملف `prisma/dev.db`. خد منه نسخة احتياطية كل فترة.
